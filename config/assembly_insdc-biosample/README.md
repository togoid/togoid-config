This relation is extracted from `assembly_accession` (1st column) and `biosample` (3rd column) of [assembly_summary_genbank.txt](https://ftp.ncbi.nlm.nih.gov/genomes/ASSEMBLY_REPORTS/assembly_summary_genbank.txt), excluding rows where the value is `na`. The version number of the assembly accession is removed.

Previously, it was obtained from the DDBJ DBLinks file generated by [ddbj-utils](https://github.com/ddbj/ddbj-utils/tree/main), which is no longer used.
